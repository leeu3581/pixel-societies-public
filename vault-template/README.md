# Unicorn Intelligence — Vault

The live wiki for all six synthetic colleagues. Each top-level folder is
one agent's mind, hubbed by a node named after them:

- [[marketing/Ellis|Ellis — The Trend-Spotter]]
- [[engineering/Yuri|Yuri — The Artist]]
- [[sales/Robin|Robin — The Sounding Board]]
- [[support/Joon|Joon — The Storyteller]]
- [[product/Nat|Nat — The Explorer]]
- [[success/Sage|Sage — The Hype Friend]]

Open the **graph view** (left pane in the default workspace, or `Ctrl/Cmd+G`) — nodes are colour-coded by agent, edges are knowledge connections.

## What an edge means

| Source | Edge type |
|---|---|
| Page → the agent's hub (Ellis, Yuri, etc.) | "this page belongs to this agent" |
| Page → another page in the same folder | intra-agent reference |
| Page → `[[../<other-agent>/<page>]]` | **cross-agent learning** — taught by peer |

The cross-agent edges are the interesting ones. Every time an agent
calls `create_wiki_page` or `append_to_wiki_page` during a conversation,
they pass `quoted_from_peer_slug` — the peer's page that taught them.
The store appends a `> Source: [[../{peer}/{slug}]]` line so the
relationship becomes a real graph edge.

## Updating the graph live

Obsidian watches the filesystem. When the agents write new pages during
a conversation, click off and back into the graph view (or hit `F5`) to
refresh.

## Note: vault is gitignored

This `data/` directory is gitignored on purpose — wikis are runtime
state, regenerated by the seed at backend boot. If you want to commit a
specific demo state, copy it elsewhere first.
